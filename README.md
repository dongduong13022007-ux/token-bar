# token-bar

Shows a persistent token-usage bar (% of the context window used) in the status line, updated after every turn.

## Install

At the prompt of a terminal session:

```
/plugin install token-bar --marketplace dongduong13022007-ux/token-bar
```

From a shell:

```
claude plugin install token-bar --marketplace dongduong13022007-ux/token-bar
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `dongduong13022007-ux/token-bar`, then Add plugin.
